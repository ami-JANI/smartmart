# Instructions for Coding Agents

This file is for Codex and other assistants that read `AGENTS.md`. SmartMart keeps one set of rules for every assistant and team member, so read these files in this order before planning or changing anything:

1. [context.md](context.md): the project in one read (scope, team, Jira, architecture, current status) and a log of recent pushes.
2. [CLAUDE.md](CLAUDE.md): how to work. Despite its name, it applies to every assistant, not only Claude.
3. [GUIDELINES.md](GUIDELINES.md): what to build and how to structure it.
4. [COMMIT.md](COMMIT.md): how to write commit messages.

The rules that are most often missed:

- Commit and push straight to `main`, the only branch. No feature branches or pull requests unless the team asks.
- Commit messages follow COMMIT.md (Conventional Commits, header at most 72 characters) with the Jira key in a footer, for example `Refs: SCRUM-28`. Enable the hook once: `git config core.hooksPath .githooks`.
- Commit messages never mention any AI tool: no `Co-Authored-By` trailer for an assistant, no session links, no "generated by" text.
- Pull before you push. A workflow appends to context.md after each push, so `main` moves on by one commit.
